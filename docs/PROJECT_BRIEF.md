2. # Техническое задание: База знаний и ИИ-помощник Образовательного центра ФБУН ЦНИИ Эпидемиологии
   
   1. Общие сведения и цель:
   - Заказчик: Образовательный центр ФБУН ЦНИИ Эпидемиологии Роспотребнадзора.
   - Цель проекта: Создать удобный, быстрый цифровой инструмент для методистов, преподавателей и ординаторов, объединяющий структурированную базу знаний института и персонального ИИ-помощника.
   - Ключевой принцип: Никаких тяжелых внешних интеграций (без 1С, Moodle и СЭД). Инструмент должен работать быстро и удобно на компьютере и на мобильном телефоне.
   
   2. Основные разделы и возможности:
   1. Нормативно-методическая база знаний:
   - Массив данных: 1 697 документов института (РПД 2026/27 уч. года, ФОС, учебные планы РУП, программы ГИА, регламенты диссовета).
   - Быстрый поиск: мгновенный поиск по названиям дисциплин, шифрам и ключевым словам за миллисекунды.
   - Система фильтров в один клик: по видам документов (Положения, Регламенты, Порядки, Правила, Инструкции, Протоколы ПК, ГЭК, УМС, аттестаций) и по специальностям (31.08.36 Эпидемиология, 31.08.35 Инфекционные болезни, 31.08.19 Педиатрия).
   
   2. Персональный ИИ-помощник (на базе DeepSeek):
   - База знаний и память: ассистент обладает памятью стандартов ФГОС ВО, структуры учебного года института, 3 обязательных этапов ГИА, СанПиН и кандидатских минимумов.
   - Консультации: дает мгновенные, юридически точные ответы на вопросы сотрудников и обучающихся (часы практики, допуск к экзаменам, состав комиссий, публикационные требования ВАК).
   - Подготовка документов: в один клик формирует проекты официальных приказов института (о зачислении, допуске к ГИА, назначении стипендий) в формате Microsoft Word (.docx) по ГОСТ Р 7.0.97-2016 (Times New Roman 14pt, поля 30/15 мм, реквизиты Роспотребнадзора).
   
   3. Экспресс-калькулятор нагрузки преподавателей (ППС):
   - Интерактивный расчет годовой педагогической нагрузки: ввод часов лекций, семинаров, практики, руководства аспирантами и работы в ГЭК.
   - Мгновенный расчет доли ставки исходя из кафедральной нормы (750–900 ч/год) с предупреждением о перегрузке или недогрузке.
   
   4. Защита персональных данных (152-ФЗ):
   - Реальные персональные данные (ФИО, паспорта) не передаются во внешние нейросети.
   - Вся работа с обучающимися и кадрами ведется через систему обезличенных аватаров с идентификаторами (ORD-XXXX для ординаторов, ASP-XXXX для аспирантов, FAC-XXXX для преподавателей).
   
   3. Требования к интерфейсу:
   - Универсальность: единый веб-инструмент, одинаково удобный на большом мониторе компьютера и на экране смартфона.
   - Мобильный UX: нижняя панель навигации (Ассистент, База знаний, Приказы, Нагрузка), поддержка режима PWA (возможность добавить иконку на экран телефона в один клик).
   - Скорость: интерфейс открывается моментально, не требует установки дополнительных программ или прав администратора.

3. Реализовать серверный эндпоинт /api/chat с семантическим поиском и генерацией ответов по нормативному корпусу 1697 документов (регламенты ординатуры, приказы, аттестация, нагрузка ППС). Добавить сквозной E2E-тест Playwright на физическую кликабельность всех кнопок веб-интерфейса (фильтры, копирование путей, отправка вопросов ассистенту). Завершить поставку всех задач верификации в main для перехода к фальсификации D008.

4. ТЕХНИЧЕСКОЕ ЗАДАНИЕ (АСУ ОЦ ЦНИИЭ):
   1. ИНСТИТУЦИОНАЛЬНАЯ БЕЗОПАСНОСТЬ (152-ФЗ):
   - Полная изоляция публичного контура от неавторизованного доступа.
   - Обязательный экран авторизации по институциональному токену / служебному PIN-коду.
   - Все API эндпоинты возвращают 401 Unauthorized до успешной авторизации.
   
   2. ЛИКВИДАЦИЯ СИМУЛЯКРОВ И МУСОРНОГО UI:
   - Полное удаление кнопок "Скопировать путь" и технических путей файлов из интерфейса.
   - Запрет заглушек и отписок "по вашему запросу проверена база".
   - Отображение человекочитаемых названий документов с краткой аннотацией и кнопками прямого скачивания файла (DOCX/PDF).
   
   3. AI-ГЕНЕРАТОР ОФИЦИАЛЬНЫХ ДОКУМЕНТОВ НА DEEPSEEK:
   - Использование рабочего DEEPSEEK_API_KEY.
   - Генератор официальных документов ОЦ по ГОСТ Р 7.0.97-2016:
     а) Протоколы заседаний УМС (повестка, кворум Горелов/Романова, постановления).
     б) Приказы директора института (ГЭК, кандидатские комиссии, приемная комиссия).
     в) Расписания экзаменационных сессий (по группам 25ОЭ, 26ОЭ, 25ОИ, 26ОИ, 25ОП, 26ОП и аспирантуре с 25.01 по 25.02).
     г) Сводные учебные планы ординатуры (120 з.е. / 4320 ч.) и аспирантуры.
     д) Справка о кадровом обеспечении и учебной нагрузке ППС кафедр (остепененность >=70%).
     е) Локальные нормативные акты института (9 положений и порядков).
   - Прямой экспорт и скачивание сгенерированного .DOCX файла в один клик.
   
   4. РЕЕСТР НОРМАТИВНЫХ АКТОВ И ЭКСПЕРТНЫЙ КОНСУЛЬТАНТ:
   - Каталог 1697 документов института со смысловым поиском и прямым скачиванием.
   - Экспертный RAG-консультант по нормативной базе Роспотребнадзора без воды.
